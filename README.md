# Krishi Sathi

A Vercel-ready Community Engagement Project prototype for plant care and soil protection.

## What it does

- Lets a user upload a crop photo locally in the browser.
- Provides symptom-led first-aid guidance for yellow leaves, leaf spots, and pest damage.
- Explains simple soil-health practices: mature compost, mulch, and soil testing.
- Provides basic care reminders for tomato, chilli, cotton, and rice.

The current version intentionally does **not** claim to diagnose diseases from an image. It uses the uploaded image as a visual reference and gives transparent, symptom-based guidance. This is safer for a student prototype and can later be connected to an expert-reviewed AI service.

## Run locally

```bash
npm install
npm run dev
```

## Deploy on Vercel

1. Push this repository to GitHub.
2. Import the repository at [vercel.com/new](https://vercel.com/new).
3. Keep the detected framework as Next.js and click Deploy.

No environment variables are needed.
